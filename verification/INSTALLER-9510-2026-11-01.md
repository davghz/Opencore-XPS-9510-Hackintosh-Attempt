# XPS 9510 installer verification — 2026-11-01

Hardware: Dell XPS 15 9510, BIOS 1.47.0, i7-11800H, AX201 `8086:43f0`,
I2C1 `8086:43e9` / subsystem `1028:0a61`, ELAN DLL0945, Realtek RTS5260.

## Observed boot and deployment

- The user confirmed that the baseline SD recovery reached the installation
  screen. Recovery metadata identified macOS 26.6.2 / 25G83, Darwin 25.6.0.
- The original plain `XPSRECOVERY` picker entry restarted OpenCore and failed
  with `Already started`. Restoring OpenCore's two `.contentVisibility` files
  hides that loader entry; the recovery DMG is the intended boot target.
- The later native Wi-Fi/input candidate was deployed at
  `2026-11-01T10:16:20Z`. Physical read-back verified all **84 active EFI files,
  21,279,650 bytes**, and the previous EFI backup. FAT checking passed; the
  recovery image was unchanged. The backup directory on the card is
  `EFI-before-native-input-20261101`.
- Earlier SD connection/read failures required reseating/cleaning the card.
  The later verification completed without new SD read errors. This is a
  successful read-back, not a claim of long-term card reliability.
- **The native Wi-Fi/input candidate has not yet been boot-tested by the user.**
  Internal keyboard typing, Wi-Fi traffic, touchpad operation, shutdown, and
  an installed macOS system remain unverified.

## Public recipe check

Before publishing, the tracked recipe was exercised in a separate private
workspace. The pinned cctools linker and all three input kexts rebuilt on
Linux. The final EFI contained the same 84 paths as the deployed candidate;
only the three rebuilt executables and generated identity differed. After
removing those identity fields, the OpenCore configuration matched exactly.

OpenCore validation and actual kernel-collection injection were repeated for
that rebuild and passed for all 14 entries. A fresh source download passed its
SHA-256 check, while an altered cached archive and an unrecognized DSDT were
rejected. The publishable files passed a check against the private Wi-Fi and
generated identity values. These build checks do not change the pending
hardware-test status above.
